# ===================================================================
# How to create and use the "DocSafe1" environment with uv
# ===================================================================
#
# 1) Install uv (once per machine), if not already installed:
#      curl -LsSf https://astral.sh/uv/install.sh | sh
#
# 2) Create a virtual environment named "DocSafe1" (Python 3.9, matching
#    the python_version pinned in the original environment2.yml):
#      uv venv DocSafe1 --python 3.9
#
# 3) Activate it:
#      source DocSafe1/bin/activate         # bash/zsh
#      source DocSafe1/bin/activate.fish    # fish shell
#
# 4) Install every dependency listed in this file:
#      uv pip install -r requirement.txt
#
#    GPU note: step 4 installs the default PyPI "torch" wheel.
#      - For a specific CUDA build (Linux/Windows), install torch first, e.g.:
#          uv pip install torch --index-url https://download.pytorch.org/whl/cu121
#        then re-run step 4 (uv will skip torch since it's already satisfied).
#      - For CPU-only:
#          uv pip install torch --index-url https://download.pytorch.org/whl/cpu
#
# 5) System-level packages (install via your OS package manager, NOT pip/uv)
#    needed by opencv-python / building native extensions, e.g. on Debian/Ubuntu:
#      sudo apt-get install -y libgl1-mesa-glx libglib2.0-0 ninja-build
#
# 6) Run the project:
#      python train_main.py
#      python test_main.py
#
# 7) Remove the environment when no longer needed:
#      rm -rf DocSafe1
